# P0 in plain English: scaffold, tooling, CI

**What this phase built.** The empty house the rest of the project lives in, plus the first safety piece.

- **Repo layout and ports.** Folders for every part of the product (`backend/app/...`, `web/`, `eval/`, `data/`). Five "ports" (small interface files) mark the places where a later, bigger product would plug in: the language model, accounts, notifications, consent and export. Each has only the hackathon version planned.
- **Python and web projects.** Every dependency is pinned to an exact version, with lockfiles, so a build next month matches today's.
- **FalkorDB in Docker.** Pinned to image tag `6.0.2` (never `latest`). We proved query timeouts work: a runaway query is stopped after 3 seconds by default. Details are in `docs/VERIFIED.md`.
- **`make` commands.** One short command for each job (`make check`, `make up`, `make review-check`). Full output goes to log files so the screen stays readable.
- **CI.** On every push GitHub runs the lint, type checks, unit tests, FalkorDB integration test, web build and a secrets scan. It is green.
- **Safety rules, first version** (`backend/app/safety/rules.py` and `review/safety_rules.yaml`). Fourteen red-flag rules (for example a long seizure, trouble breathing, a rash that does not fade, a teen talking about self-harm). Plain code checks every parent message against them; the language model can never remove a flag. A negation like "no seizures" only cancels the exact words it sits on, so "She's not sleeping and says she wants to die" still fires. A second reviewer (the advisor) found several ways real emergencies could slip through; they were fixed and each is now a test (`backend/tests/test_safety_adversarial.py`).
- **Draft review files.** Rules, 40 "common explanation" cases, demo stories and doctor letters are written by Claude and marked DRAFT. A human must read them and change line 1 to REVIEWED. `make review-check` also cross-checks the files against each other (for example, Maya's story must trigger the seizure rule and Arjun's must trigger nothing).

**What it does not do yet.** No medical knowledge base, no scoring, no questions, no real web screens. Those come in P1 onward.

**Things worth knowing.**
- The safety rules are in English only and deliberately over-cautious.
- The Tele-MANAS number (14416) was read from the official site's code; a human should glance at the live page.
- A guard script briefly mistook the demo-story and doctor-letter templates for REVIEWED files and blocked writing the drafts; the human copied the drafts in and marked them reviewed.
