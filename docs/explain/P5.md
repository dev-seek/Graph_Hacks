# Phase 5 in plain English: the clinic's shared memory, and one honest test

## What we built
**The centre brain.** A clinic keeps a "centre" graph of 300 made-up cases (250 solved, 50 still open) built from public research records. Each case has signs, a clinician (a role name such as "Clinician A, neurogenetics") and, if solved, the protocol used (for example "trio exome sequencing") and how long it took. A clinician can pick an open case and see the five closest solved cases, who solved them, which tests they used and how long it took. The page also shows which signs link many cases, which cases cluster, how fast each protocol is, and lets staff add notes. "Ask the centre" matches a typed question to one of six fixed checks; it never writes free-form database queries. All of it is labelled illustrative clinic data.

**Knowledge-update check.** We built a second knowledge base from a medical release a year older. The "re-check" button copies the centre, re-scores every open case against the newer release and lists cases that now show a much stronger rare-disease pattern (2 of 50 did).

**The frozen test.** We ran the system once on 5,336 held-out published cases, with simulated parent answers, under a plan written down first (`docs/adr/0013-frozen-evaluation-preregistration.md`). Nothing was tuned afterwards.

## What the numbers say (leave-publication-out, the honest setting)
- Right condition in the top 10 for **13.0%** of cases after four rounds of questions (14.3% after the simulated doctor visit); top-1 is 3.4%. Asking questions helps a little over the story alone (11.8%, gain +0.7 to +1.7 points) but does **not** beat the simple "ask the most common sign" baseline (13.2%; on the standard kb Ours is 1.0 to 2.7 points below it). The planner's edge is not demonstrated on this test.
- 68.7% of test cases still have the target condition annotated once the papers about them are removed; the rest count as misses, so the headline is low by design. Counting only cases whose target is still annotated: 18.9% (20.8% after the doctor visit).
- On the 40 everyday-case vignettes: 0% false referrals, 22.5% sent to a doctor unnecessarily.
- With the standard (leaky) knowledge base the same system reaches 55.7% top-10, which shows how much of the apparent skill comes from having read the same papers.

## Limits to state in the README
Simulated answers, not real parents; published cases, not a clinic; centre data is synthetic; not a clinical validation; referral sensitivity is low (about 13%) because the simulated doctor visit often reveals too few findings.

## Surprises
FalkorDB 6.0.2 crashed once on an aggregate over a missing value, losing the unsaved centre graph, and after the restart the knowledge base searched terms slightly differently until it was rebuilt. Both are recorded with workarounds.
